# Profil Pribadi — Muhammad Nurhalim

Website profil responsif dengan HTML5, Bootstrap 5, CSS, dan JavaScript. Siap untuk GitHub Pages.

## File
- `index.html` — struktur dan konten halaman.
- `style.css` — desain tambahan.
- `script.js` — interaksi navigasi dan tahun footer.
- `assets/foto-profil.jpg` — foto diri yang perlu lu tambahkan.

## Wajib disesuaikan sebelum dikumpulkan
1. Masukkan foto diri ke folder `assets` dengan nama `foto-profil.jpg`.
2. Ganti `emailkamu@example.com` dengan email aktif.
3. Sesuaikan level Bahasa Inggris dan persentase skill dengan kemampuan sebenarnya.
4. Periksa kembali bio, minat, dan tautan GitHub.

## GitHub Pages
Upload isi folder ini ke root repository. Lalu buka **Settings → Pages → Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, lalu Save. Untuk repository `username.github.io`, alamatnya `https://username.github.io/`.

Bootstrap dan Bootstrap Icons menggunakan CDN, sehingga perlu koneksi internet saat halaman dibuka.
